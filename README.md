DocPad — текстовый редактор для Android
Полноценный офлайн-редактор документов для смартфона: функции, привычные по Microsoft Word, в интерфейсе, удобном для сенсорного экрана.
Возможности
Файлы
Открытие: DOCX (Word 2007+), ODT (LibreOffice), RTF, HTML, TXT (UTF-8 и Windows-1251), Markdown.
Сохранение: DOCX, ODT, RTF, HTML, TXT, Markdown; PDF — через системную печать («Сохранить как PDF»).
«Сохранить» записывает в исходный файл, «Сохранить как» — в любую папку или облако (Google Диск и т.п.).
Открытие файлов из файлового менеджера, почты и мессенджеров («Открыть с помощью DocPad»), приём текста через «Поделиться».
Поделиться документом в любом формате или просто текстом.
Автосохранение черновика: после закрытия приложения документ восстанавливается. Список последних файлов.
Шаблоны: письмо, резюме, отчёт, протокол встречи, заявление, список дел.
Шрифт и символы
22 встроенных шрифта с кириллицей, в том числе метрически совместимые замены Times New Roman, Arial, Calibri, Cambria, Courier New — документы Word выглядят как в оригинале.
Системные шрифты Android, ввод любого имени шрифта, добавление своих шрифтов TTF/OTF/WOFF.
Размер 1–1638 пт, увеличение/уменьшение, жирный, курсив, подчёркнутый, зачёркнутый, надстрочный и подстрочный, цвет текста (палитра Word + любой цвет), цвет выделения, смена регистра, очистка формата, формат по образцу.
Таблица символов: пунктуация, математика, индексы, дроби, греческие, валюты, стрелки, фигуры, знаки, расширенная латиница и кириллица, эмодзи, ввод по коду Юникода.
Абзацы и стили
Выравнивание, отступы (слева, справа, первая строка, выступ), интервалы до/после, междустрочный интервал (множитель или точно в пт), заливка и рамка абзаца, «с новой страницы», направление справа налево.
Маркированные, нумерованные (1., a., A., i., I., 01.) и многоуровневые списки, чек-листы, «начать нумерацию с…».
Стили: Обычный, Название, Подзаголовок, Заголовки 1–6, Цитата, Код, собственные стили.
Вставка
Таблицы (выбор размера пальцем): добавление/удаление строк и столбцов, объединение и разделение ячеек, заливка, границы, строка заголовка, выравнивание.
Рисунки из галереи и файлов: размер, положение, обтекание, поворот, отражение, рамка, замещающий текст.
Ссылки, сноски, оглавление (с переходом по нажатию), разрыв страницы, горизонтальная линия, дата и время, табуляция.
Колонтитулы и номера страниц.
Макет и вид
Размер бумаги (A3, A4, A5, B5, Letter, Legal), ориентация, поля (включая ГОСТ), колонки.
Мобильный вид (текст по ширине экрана) и разметка страницы с границами страниц; масштаб двумя пальцами.
Режим чтения, режим фокуса, полноэкранный режим, панель навигации по заголовкам, знаки абзацев ¶.
Светлая/тёмная тема, 10 цветов оформления, цвет страницы (белый, сепия, серый, зелёный, ночной).
Рецензирование
Поиск и замена (регистр, слово целиком, регулярные выражения) с подсветкой всех совпадений.
Статистика: слова, знаки, абзацы, предложения, авторские листы, время чтения.
Проверка орфографии, чтение вслух, примечания (сохраняются в DOCX как примечания Word), режим «только чтение», проверка безопасности, инспектор документа, защищённый просмотр.
Точная правка пальцем (вкладка «Правка»)
Кнопки перемещения курсора: по символу, слову, строке, в начало/конец строки и документа.
Выделение слова, предложения, абзаца; расширение выделения по символу, слову, строке.
Перемещение абзаца выше/ниже, дублирование и удаление абзаца, удаление слова целиком.
Дополнительные инструменты
Полный диалог «Шрифт…»: стили подчёркивания (двойное, точечное, штриховое, волнистое) и его цвет, двойное зачёркивание, малые и все прописные, тень, межбуквенный интервал, смещение вверх/вниз — всё сохраняется в DOCX.
Типограф: кавычки «ёлочки», тире, многоточие, неразрывные пробелы после предлогов, удаление лишних пробелов.
Очистка текста (после копирования из интернета/PDF): двойные пробелы, пустые абзацы, лишние переносы строк.
Сортировка абзацев и списков А→Я / Я→А, сортировка таблицы по столбцу (числа сортируются как числа).
Преобразование «текст ↔ таблица», 8 готовых стилей таблиц.
Формулы (упрощённый LaTeX: степени, индексы, дроби, корни, греческие буквы, знаки), буквица, спецзнаки (неразрывный пробел, мягкий перенос и др.), названия «Рисунок N», «Таблица N».
Вкладка «Дизайн»: оформление по ГОСТ в одно касание, подложка (ЧЕРНОВИК, КОНФИДЕНЦИАЛЬНО, свой текст), цвет страницы, автоматические переносы.
Гибкая настройка под сенсорный экран
Лента вкладок как в Word; лента сворачивается, закрепляется (📌) или автоматически скрывается при наборе.
Панели сверху или снизу (у клавиатуры — удобно для большого пальца).
Размер кнопок (4 варианта), подписи под кнопками, лента в два ряда, скрытие вкладок.
Панель быстрого доступа с вашим набором и порядком команд.
Скрытие верхней панели при прокрутке, строка состояния, «не выключать экран», блокировка ориентации.
Безопасность
DocPad рассчитан на безопасное открытие документов, полученных из любых источников.
Приложение полностью отключено от интернета. В манифесте явно удалены разрешения INTERNET и ACCESS_NETWORK_STATE (даже если их попытается добавить библиотека). Встроенный WebView дополнительно блокирует любые запросы, кроме собственных файлов приложения; отключены Safe Browsing и статистика WebView; резервное копирование данных в облако выключено. Ссылки из документов открываются во внешнем браузере только если вы это разрешите в настройках, и каждый раз с подтверждением.
Ничего из документа не выполняется. Макросы VBA/Basic, скрипты, ActiveX, OLE-объекты, поля DDE, внешние шаблоны и встроенные фреймы игнорируются и удаляются. Действует строгая политика безопасности контента (CSP), запрещающая любой посторонний код.
Проверка каждого файла при открытии:
настоящий тип файла определяется по содержимому (исполняемый файл с расширением .docx не откроется; RTF под видом .doc будет обнаружен);
поиск макросов, внедрённых объектов, ActiveX, DDE-полей, внешних шаблонов и связей, ссылок со скриптами, внешних картинок-«маячков», скрытого текста, символов смены направления, ссылок с подменённым адресом;
защита от ZIP-бомб и XML-бомб, ограничение размера файла (60 МБ);
строгая очистка содержимого: в редактор попадают только текст, оформление, таблицы и встроенные картинки.
Защищённый просмотр (как в Word): файлы из почты и мессенджеров, а также файлы с найденными угрозами открываются только для чтения — лента скрыта, ссылки отключены, можно запретить снимки экрана. Кнопка «Подробнее» показывает отчёт о найденных угрозах, «Разрешить редактирование» снимает защиту. Файл с опасными элементами никогда не перезаписывается — сохраняется очищенная копия. Режим настраивается в «Настройки → Безопасность»; включить вручную — «Рецензирование → Защищённый просмотр».
Инспектор документа удаляет перед отправкой примечания, ссылки, рисунки, сноски, выделение цветом и имя автора.
Мост между интерфейсом и Android разрешает запись только в файлы, которые вы сами открыли или сохранили, и не принимает адреса file://.
Как собрать APK через GitHub (без компьютера)
Сборка выполняется бесплатно на серверах GitHub. Нужен только аккаунт на github.com.
Способ 1 — с телефона
Войдите на github.com (в браузере, режим «Версия для ПК» удобнее).
Нажмите + → New repository. Имя — например, DocPad. Выберите Public или Private. Нажмите Create repository.
На странице репозитория нажмите uploading an existing file (или Add file → Upload files). Выберите файл DocPad.zip — не распаковывая его. Нажмите Commit changes.
Нажмите Add file → Create new file. В поле имени файла введите ровно:
.github/workflows/build.yml
(после каждого «/» GitHub сам создаёт папку). Вставьте в поле текст из файла build.yml (он приложен отдельно, тот же текст лежит в архиве по пути .github/workflows/build.yml). Нажмите Commit changes.
Откройте вкладку Actions. Сборка «Build APK» запустится сама и займёт около 5–10 минут. Зелёная галочка — готово.
Вернитесь на главную страницу репозитория → справа блок Releases → DocPad 1.0.N → скачайте файл DocPad-1.0.N.apk.
Откройте APK на телефоне. Если Android спросит — разрешите установку из этого источника (браузера/файлового менеджера).
Способ 2 — с компьютера
Создайте репозиторий (шаги 1–2 выше).
Распакуйте DocPad.zip. Откройте папку DocPad и перетащите всё её содержимое (папки app, keystore, .github и файлы) в окно Add file → Upload files. Нажмите Commit changes.
Если скрытая папка .github не загрузилась (так бывает на macOS/Windows), создайте файл workflow вручную, как в шаге 4 способа 1.
Дальше — шаги 5–7.
Второй способ удобнее для последующих изменений: можно править отдельные файлы прямо на GitHub (значок карандаша), и после каждого сохранения будет собираться новая версия.
Способ 3 — Android Studio
Откройте папку DocPad в Android Studio (Hedgehog или новее) → Build → Build APK(s). Шрифты из app/fonts.zip распакуются автоматически при первой синхронизации Gradle.
Обновление приложения
Каждый новый коммит в репозиторий запускает сборку и публикует новый релиз. Номер версии растёт автоматически, а все сборки подписаны одним ключом (keystore/docpad.jks), поэтому новая версия устанавливается поверх старой без потери настроек и черновика.
Запустить сборку вручную: Actions → Build APK → Run workflow.
Свой ключ подписи (необязательно)
Ключ в папке keystore подходит для личного использования. Если репозиторий публичный и вы хотите, чтобы ваш ключ никто не знал:
Создайте ключ: keytool -genkeypair -keystore my.jks -alias myalias -keyalg RSA -keysize 2048 -validity 10000
Закодируйте его: base64 -w0 my.jks (Linux) / certutil -encode my.jks out.txt (Windows).
В репозитории: Settings → Secrets and variables → Actions → New repository secret — добавьте KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD.
Учтите: приложение, подписанное другим ключом, не установится поверх предыдущего — старую версию придётся удалить.
Если сборка не прошла
Откройте Actions → неудачный запуск (красный крестик) → шаг с ошибкой. Скопируйте последние строки лога — по ним легко найти и исправить причину.
Ограничения
Старый двоичный формат .doc (Word 97–2003) не открывается — пересохраните файл в .docx.
PDF создаётся через системную печать Android (выберите «Сохранить как PDF»); редактировать PDF нельзя.
Режим «Разметка страницы» показывает границы страниц приблизительно; точная разбивка — при печати/PDF и в Word.
Сложные объекты Word (надписи, фигуры SmartArt, формулы, режим исправлений) при открытии упрощаются: текст сохраняется, оформление может отличаться.
Проверка орфографии выполняется клавиатурой Android (Gboard и др.).
